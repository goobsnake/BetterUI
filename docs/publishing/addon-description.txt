[SIZE="4"][B][COLOR="darkorange"]BetterUI - Gamepad Interface Overhaul[/COLOR][/B][/SIZE]

BetterUI modernizes ESO's gamepad UI with cleaner navigation, richer tooltips, configurable layouts, and high-impact quality-of-life upgrades for Inventory, Banking, and Resource Orb Frames.

[COLOR="darkorange"][SIZE="3"][B]What's New in v3.00 (Major Update)[/B][/SIZE][/COLOR]
[LIST]
[*]Complete visual overhaul and major system refactor around the Resource Orb Frames feature
[*]New high-fidelity scroll indicators and cleaner full-row selection visibility
[*]Unified header-sort behavior with clearer sort indicators and Y-menu sort actions
[*]Banking and Craft Bag multi-select batch workflows (including quantity dialogs)
[*]Currency refresh for PTS v11.3.0: Trade Bars naming update, Seals of Endeavor, and Tome Points support
[/LIST]

[COLOR="darkorange"][SIZE="3"][B]Requirements[/B][/SIZE][/COLOR]
[LIST=1]
[*][URL="https://esoui.com/downloads/info7-LibAddonMenu.html"]LibAddonMenu-2.0[/URL] is required for BetterUI to load and expose settings.
[/LIST]
